--- layout: default title: Home Assistant Google Integration permalink: /ha/ --- # Home Assistant Google Integration This page describes a private, noncommercial Home Assistant integration operated by the owner of this website. The integration connects a personal Home Assistant installation with Google services, including Google Nest devices and Google Calendar, for home automation and scheduling. Access is authorized by the Google account owner through Google's OAuth consent flow. This application is intended for the owner's personal use and is not offered as a public service. For details about the handling of Google account information, see the [Privacy Policy](/ha/privacy.html).
